말차 라이브러리 사용법과 통계

1. 데이터 업데이트

엑셀의 data 시트를 편집하고 CSV UTF-8(쉼표로 분리)로 저장하세요. 화면의 ‘CSV 불러오기’로 바로 분석하거나, GitHub의 matcha_data.csv를 교체합니다. 엑셀(.xlsx) 자체는 브라우저에서 읽지 않습니다. 불러온 CSV는 현재 화면에만 적용되며 새로고침하면 다시 원본을 읽습니다.

HTML만 더블클릭해도 내장 예제로 작동합니다. 웹 주소에서는 같은 폴더의 CSV를 자동으로 읽습니다. 잘못된 CSV를 읽으면 기존 유효 데이터가 유지되고 오류가 표시됩니다. GitHub에 올리는 데이터는 공개될 수 있습니다.

2. 성분과 데이터 조건

예측에는 글루탐산(Glu)·테아닌·카페인 세 성분을 사용합니다. 세 성분이 모두 있는 행만 사용하며, 글루타민 열은 필요하지 않습니다. 단위는 분말 건물 기준 mg/g_dw입니다. mg/100g 값은 100으로 나눕니다. as-is 값을 건물 기준으로 바꾸려면 수분 함량이 필요합니다. 음료 mg/L와 직접 혼합하지 마세요.

한 행은 한 시료의 패널·반복 평균입니다. 동일 원료의 재측정은 같은 lot_id를 사용하세요. 동일 로트의 여러 행은 학습 가중치를 늘리므로 가능하면 로트당 한 행으로 집계하세요. data_type은 real로 통일하며 등록된 전체 데이터를 학습합니다. 현재 제공 수치는 가상이며 notes에 표시되어 있습니다. 실측값으로 교체할 때 notes도 실제 측정 이력으로 갱신하세요. 비교 가능한 조제·평가 조건의 데이터를 등록하세요.

3. 예측 방법

성분별 z=(x−학습 평균)/학습 표준편차로 표준화합니다. 릿지 회귀는 Σ(y−예측)²+λΣβ²를 최소화하며 λ=1, 절편은 벌점에서 제외합니다. k-NN은 표준화 거리 RMS가 가까운 5개 시료를 1/(거리+10⁻⁶)로 가중합니다. 성분이 완전히 같은 시료가 있으면 그 시료들의 평균만 사용합니다. 출력은 0–10 범위로 제한됩니다.

학습 범위를 벗어나면 외삽 경고가 표시됩니다. 범위 안이어도 검증된 예측이라는 뜻은 아닙니다. 릿지의 0–10 제한은 외삽의 신뢰성을 보장하지 않습니다. 예측구간·통계적 신뢰확률은 제공하지 않습니다.

4. 유사도와 검증의 차이

맛 유사도 = 100×[1−√평균{(예측 맛−DB 관능값)²}/10]. 네 관능축에 같은 가중치를 둔 편의적 0–100 지표입니다. 기존 시료의 관능값은 예측 학습에도 쓰이므로 이 점수는 독립 검증이 아닙니다.

성분 거리 = √평균{(입력 z−시료 z)²}. 교차검증에서는 한 로트 전체를 제외하고 표준화·모델을 매번 다시 학습합니다. MAE=평균|오차|, RMSE=√평균(오차²), R²=1−SSE/SST. R²는 전체 제외 예측을 합쳐 계산하며 관능값이 상수이면 ‘—’입니다. 평균모형은 각 학습 폴드의 관능 평균만 예측하는 기준선입니다.

최소 8개 시료·5개 로트는 화면 계산을 위한 하한일 뿐 과학적 충분성 기준이 아닙니다. 실측 데이터로 모델을 고르고 성능을 보고하려면 별도 외부 로트 검증이 필요합니다. 산지별 평균은 산지의 본질적 맛 특성을 증명하지 않습니다.

5. 식품과학적 해석

글루탐산은 감칠맛, 카페인은 쓴맛에 기여하며 테아닌 등은 혼합물의 맛에 관여합니다. 카테킨·유기산·당·입도·조제 농도·온도·물 성분이 누락되어 특히 떫은맛과 단맛의 설명력은 제한됩니다. 본 시제품은 향·색·입자감 또는 아이스크림 배합에서의 맛을 직접 예측하지 않습니다.
